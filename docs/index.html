Ce qu’il sait faire

Reprise de la lecture

Ferme une vidéo en cours de route : elle repart là où tu l’avais laissée.

Liste de lecture

Glisse plusieurs fichiers dans la fenêtre : ils s’enchaînent tout seuls.

Sous-titres

Ajoute un fichier .srt ou .vtt en un clic.

Capture d’image

Appuie sur S pour enregistrer l’image affichée dans ton dossier Images.

Raccourcis clavier

Espace, flèches, F plein écran, M muet, L liste de lecture.

Vitesse réglable

De 0,5× à 2× pour les cours, les tutoriels et les longues vidéos.

Formats lus : MP4, WebM, MKV (H.264), MOV, MP3, WAV, FLAC, M4A. Les fichiers AVI, HEVC/H.265 et l’audio AC3/DTS ne sont pas encore pris en charge.

Installer en 3 étapes

  1. Télécharge l’installeur : le fichier se termine par .exe.
  2. Double-clique dessus. Si Windows affiche « Windows a protégé votre ordinateur », clique sur Informations complémentaires, puis sur Exécuter quand même.
  3. Lance Lumina Player et glisse une vidéo dans la fenêtre.

Le logiciel n’est pas encore signé avec un certificat payant, c’est pourquoi Windows affiche cet avertissement. Le code source est public sur GitHub : tu peux le vérifier toi-même. Sous Linux, tu peux le compiler avec npm run dist:linux.
